# Token documentation

This directory stores versioned project PDFs submitted through Synthwav's Token Manager.

- Maximum PDF upload size: **4 MB**. Files must be readable and not password protected.
- Each upload receives its own path containing a token-family identifier, the PDF's SHA-256 hash, and an upload identifier.
- Existing PDFs are not overwritten by the upload process.
- Reviews apply to an exact PDF version. Approved links are pinned to its GitHub commit.
- Replacing the content requires a new submission and Admin review.

Files here may be pending review, rejected, revoked, or superseded. Presence in this directory is **not** proof of approval. Consult the project's current Token Insight Profile (TIP) on [Synthwav](https://synthwav.io) for its active status.

Submit documentation through **Token Manager → Project Transparency → Documentation**. Review status and audit history are maintained by Synthwav rather than stored in these PDFs.
